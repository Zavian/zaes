# zaes.dev

Personal site and portfolio of Emanuele Sbabo — web developer and technical QA analyst based in Leiden, Netherlands.

**Live at [zaes.dev](https://zaes.dev)**

## What's on it

- **About & work** — what I do day to day: multi-brand web platforms, migrations, DNS/SSL for 100+ domains, cross-browser QA.
- **Projects**
  - [Tabletop RPG Toolset](https://zaes.dev/projects/tabletop-toolset) — Lua/XML automation suite for Tabletop Simulator.
  - [RPG Card Creator](https://zaes.dev/projects/rpg-card-creator) — browser tool for designing and exporting tabletop cards.
  - [Campaigns & Narrative Systems](https://zaes.dev/projects/aclorth) — a long-running tabletop setting documented in a 1,000,000+ word Obsidian vault.
- **Other** — raid leadership and the recruitment automation built around it.
- **CV** — viewable on the site or as a [PDF](https://zaes.dev/cv.pdf).

## How it's built

React, TypeScript, Tailwind CSS and Vite. Every page is prerendered to static HTML at build time and deployed to GitHub Pages on each push to `main`.

All copy lives in `src/content/`, so updating the site means editing those files — page text, metadata, sitemap and `llms.txt` are generated from them.
